\section{Methodology}
\label{sec:method}

In this section, we formalize the rollout-free competence boundary forecasting setting, define the candidate forecasting rules, present the theoretical properties of policy-conditional versus policy-agnostic metrics, and detail our test-time adaptation diagnostic protocol.

\subsection{Environment and Problem Setting}
\label{sec:method:env}

We evaluate policies in continuous visual control on the \textbf{Visual Pursuit} domain.
The agent receives high-dimensional pixel observations $x_t \in \mathbb{R}^{48 \times 48 \times 3}$ (constructed from a 3-frame stack of $48 \times 48$ RGB frames) and emits continuous 2D velocity actions $a_t = (\Delta x, \Delta y) \in [-1, 1]^2$ to control a tracking reticle toward a dynamically moving target.
The target moves with velocity $v_{\mathrm{target}} = 0.8$\,px/step, and the reticle has a maximum displacement of $2.0$\,px/step.
The instantaneous task reward is the negative Centre-of-target Localization Error (CLE):
\begin{equation}
    r_t = - \|p_{\mathrm{reticle}, t} - p_{\mathrm{target}, t}\|_2.
\end{equation}
An episode is classified as successful if the episode-mean CLE remains strictly below $5.0$\,pixels (relative to an unguided random policy baseline of $22.05$\,px).

\paragraph{Controlled Visual Shift Modalities.}
To model realistic perceptual distribution shifts, we evaluate 5 parameterized physical shift families $T_s^\kappa$ with severity $s \in [0.0, 1.0]$, where $s = 0.0$ is strictly verified as the exact identity transformation ($T_0^\kappa = \mathrm{id}$):
\begin{enumerate}
    \item \textbf{Background ($\kappa = \text{background}$):} Moving procedural sinusoidal chromatic grating.
    \item \textbf{Sensor Noise ($\kappa = \text{noise}$):} Additive independent Gaussian pixel noise $\mathcal{N}(0, \sigma^2(s))$.
    \item \textbf{Distractors ($\kappa = \text{distractor}$):} Moving secondary distractors and visual clutter in the arena.
    \item \textbf{Viewpoint Jitter ($\kappa = \text{viewpoint}$):} Affine perspective scale and camera translation shifts.
    \item \textbf{Photometric Gain ($\kappa = \text{color\_gain}$):} Channel-wise photometric color scaling.
\end{enumerate}

\paragraph{Information Constraint.}
Let $\pi$ be a trained policy. A rollout-free forecaster $\mathcal{F}$ receives the policy's weights, a clean reference dataset $\mathcal{D}_0$ collected at severity $s = 0.0$, and the ability to render corruptions $T_s^\kappa$ on recorded clean frames.
Crucially, $\mathcal{F}$ receives \textbf{zero rollouts under any shifted condition} ($s > 0$).
Its objective is to predict the critical corruption severity $s^*_{\pi, \kappa}$ at which the policy's success rate drops below $50\%$ of its nominal clean performance.

\subsection{Candidate Rollout-Free Forecasters}
\label{sec:method:forecasters}

Let $\phi: \mathcal{X} \to \mathbb{R}^D$ denote the policy's visual feature encoder ($D = 50$). Given clean frames $x \sim \mathcal{D}_0$ and synthetic shifted frames $x' = T_s^\kappa(x)$, we evaluate nine candidate scoring functions:
\begin{enumerate}
    \item \textbf{Policy Feature $k$NN (\texttt{knn\_policy}):} Mean Euclidean distance to the $k = 5$ nearest neighbors in the clean latent feature bank $\mathcal{B}_{\mathrm{clean}} = \{\phi(x_i)\}_{i=1}^M$:
    \begin{equation}
        S_{\mathrm{knn\_pol}}(x') = \frac{1}{k} \sum_{j \in \mathrm{NN}_k(\phi(x'), \mathcal{B}_{\mathrm{clean}})} \|\phi(x') - \phi(x_j)\|_2.
    \end{equation}
    \item \textbf{Mahalanobis Latent Distance (\texttt{maha\_policy}):} Distance scaled by the clean feature covariance matrix $\Sigma$:
    \begin{equation}
        S_{\mathrm{maha}}(x') = \sqrt{(\phi(x') - \mu)^\top \Sigma^{-1} (\phi(x') - \mu)}.
    \end{equation}
    \item \textbf{Centroid / Lyu Bound (\texttt{cent\_policy}):} Distance to the clean feature mean centroid: $\|\phi(x') - \mu_{\mathrm{clean}}\|_2$, representing the empirical probe motivated by Lyu et al.~\citep{lyu2024generalization}.
    \item \textbf{Action Disagreement (\texttt{act\_disagree}):} Divergence between actions output by the policy under perturbed vs clean observations: $\|\pi(x') - \pi(x)\|_2$.
    \item \textbf{$Q$-Value Drop (\texttt{q\_drop}):} Expected reduction in critic value: $Q_\theta(\phi(x), \pi(x)) - Q_\theta(\phi(x'), \pi(x'))$.
    \item \textbf{Critic Temporal Gap (\texttt{critic\_gap}):} Bellman residual error of the critic evaluated on perturbed transitions without reward updates.
    \item \textbf{Raw-Pixel $k$NN (\texttt{knn\_pixel}):} $k$NN distance evaluated directly in normalized flattened pixel space.
    \item \textbf{Random Projection $k$NN (\texttt{knn\_random}):} $k$NN distance evaluated after projection through a fixed, untrained random Gaussian matrix $R \in \mathbb{R}^{D \times d_{\mathrm{pix}}}$.
    \item \textbf{Semantic $k$NN Features (\texttt{sem\_knn\_policy}):} Latent $k$NN distance weighted by spatial action gradients.
\end{enumerate}

\paragraph{Isotonic Calibration Protocol.}
Continuous boundary forecasts $\hat{s}_{\pi, \kappa}$ are obtained via leave-one-kind-out isotonic regression: for each target shift kind $\kappa$, the calibration mapping $S \mapsto \hat{s}$ is fit strictly on the remaining four shift kinds across clean calibration seeds, ensuring completely held-out evaluation.

\subsection{Theoretical Foundations}
\label{sec:method:theory}

\begin{proposition}[Identifiability Limitation of Policy-Agnostic Scores]
\label{prop:identifiability}
Let $D$ be any observation score computed from clean and shifted observation laws $(P_0, P_s)$ without access to policy weights $\pi$. Suppose shift component $z$ takes a fixed value $z_0$ in clean observations. Then for any $s_0 \in (0, 1)$, there exist two policies $\pi_a, \pi_b$ with identical clean behavior such that $s^*_{\pi_a} \le s_0$ while $s^*_{\pi_b} = 1$ (censored).
\end{proposition}

\begin{proposition}[AUROC Portability Across Regime Mixes]
\label{prop:mixture}
Let an evaluation distribution consist of a mixture of a plateau regime (fraction $1-q$, failure rate $f_p$) and a cliff regime (fraction $q$, failure rate $f_c$). If a score achieves within-regime failure AUROC $a$ on the cliff and $a_p$ on the plateau, the global empirical AUROC is given by:
\begin{equation}
    \mathrm{AUROC}(q) = \frac{q(1-q)\left[a f_c (1-f_p) + (1-a) f_p (1-f_c)\right] + q^2 f_c (1-f_c) a + (1-q)^2 f_p (1-f_p) a_p}{\left[q f_c + (1-q) f_p\right] \left[q (1-f_c) + (1-q) (1-f_p)\right]}.
\end{equation}
\end{proposition}

\subsection{Test-Time Adaptation Diagnostic Protocol}
\label{sec:method:tta}

To evaluate whether test-time self-supervision can reverse performance collapse, we implement an online test-time adaptation module (\texttt{ttss/adapter.py}).
During deployment, the agent maintains an observation window $X_{\mathrm{win}}$ of length $W = 8$.
Candidate encoder parameters $\phi'$ are generated via SGD updates on a self-supervised moment-matching objective:
\begin{equation}
    \mathcal{L}_\mathrm{TTSS}(\phi; X_{\mathrm{win}}) = \|\mu_{\mathrm{test}} - \mu_{\mathrm{off}}\|_2^2 + \|\sigma^2_{\mathrm{test}} - \sigma^2_{\mathrm{off}}\|_2^2.
\end{equation}
A trust-region safeguard evaluates candidate weights $\phi'$: the update is committed if and only if $\mathcal{L}_\mathrm{TTSS}(\phi'; X_{\mathrm{win}}) < \mathcal{L}_\mathrm{TTSS}(\phi; X_{\mathrm{win}}) - \delta$. Otherwise, the update is rejected and encoder parameters revert to $\phi$.
All arms (\texttt{none}, \texttt{ttt}, \texttt{ttss}) share identical base learning rates ($\eta = 0.001$), buffer sizes ($8$), and moment weights ($1.0$), isolating the single factor of safeguard update rejection.
